# Movie-Ticket-Booking-Management-Application# Movie Ticket Booking Management Application

## Project Description

This project is a Movie Ticket Booking Management Application
developed using Pega App Studio.

## Pega Application

You can access the application here:

[Open Pega App Studio Application](PASTE_YOUR_PEGA_LINK_HERE)

## Case Life Cycle

The application contains the following stages:

1. Booking Request
2. Information Gathering
3. Ticket Availability
4. Payment Processing
5. Ticket Issuance
6. Completion

## Features

- Customer details collection
- Movie and show time selection
- Theatre and seat availability
- Ticket allocation approval
- Payment processing
- Electronic ticket issuance
- Booking confirmation
